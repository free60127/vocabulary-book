# 单词本 · Vocabulary Book

查一个单词、短语或句型，得到一份**能直接用**的详细讲解：意思与词性、褒贬色彩、情感强度、
语域、词根词缀拆解、助记画面、适用场景与**不该用的场合**、近义词逐个讲清差别、
体现差别的例句。存进自己的单词本，按**间隔重复（SM-2）**安排每日复习，还能一键出题自测。

> 与「回译本」（Back-Translate Studio）是同一套基础设施与设计语言的姊妹项目：
> 账号、云同步、AI 接入设置、任务轮询、限流与安全边界全部沿用那边已经跑过测试的实现。

## 跑起来

    npm install
    cp .env.example .env      # 填 AI_API_KEY（Base URL / 模型按需改）
    npm run server            # 后端 http://localhost:8790（同时托管打包好的前端）
    # 开发模式另开一个终端：
    npm run dev               # 前端 http://localhost:5173，/api 已代理到后端

没有 Key 时也可以在「AI 设置」里临时填自己的（只存本机浏览器）。

## 几个关键设计（都是踩过的坑）

- **排期与词条分开存**：词条是"内容"（会同步、会导出分享），排期是"我练到哪了"。
  分开之后把词条拷给同学不会连带把复习进度带过去。
- **删除留墓碑**：云同步是并集合并，删除不留标记就会"删了又出现"。
  墓碑过滤做成**合并之后的统一收口** —— 第一版只在本子已存在那条分支里判断，
  新本子走"整体加入"那条路时墓碑完全失效（有测试钉着）。
- **单条过大丢弃、超长字段截断**：一条脏数据不该卡住整次同步。
- **服务端生成词条 id**：客户端靠它做合并、去重、删除墓碑；模型不给也不该让它给。
- **查词走异步任务 + 轮询**，不是长连接：手机端/弱网下长请求会被挂起甚至中断。
- **自定义 Base URL 禁私网 + 不跟随重定向**：防 SSRF（含 IPv4 映射的 IPv6 这种绕过）。
- **API Key 归一化**：把粘贴时混进来的非 ASCII 字符/空白清掉（否则会抛一句看不懂的英文错）。

## 环境变量

见 `.env.example`。最常改的几个：

| 变量 | 说明 |
| --- | --- |
| `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY` | 任意 OpenAI 兼容接口 |
| `PORT` | 后端端口（默认 8790） |
| `ALLOW_SERVER_KEY` | 设 `0` 强制访客自带 Key（公网开放时建议设 0） |
| `ALLOW_ORIGIN` | 前后端分开部署时的跨域白名单 |
| `UPSTASH_REDIS_REST_URL/TOKEN` | 配了才会启用账号 + 持久云同步 |
| `RATE_LIMIT_PER_MIN` / `MAX_INFLIGHT_JOBS` | 限流与并发闸门 |
